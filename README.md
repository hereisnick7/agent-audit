# /agent-audit — Sub-Agent Prompt Auditor v1.0

> Скилл + суб-агент для Claude Code. Read-only token-economy/структурный аудит промптов твоих собственных `.claude/agents/*.md` суб-агентов — находит дубли, устаревшие ссылки, разъехавшиеся списки-двойники, скрытые противоречия между правилами и "раздутую" прозу, которую можно сократить без потери смысла.

---

## Что делает

Ты пишешь суб-агентов для Claude Code, они растут, обрастают правилами — и со
временем в промпте накапливается: одно и то же правило сказано дважды другими
словами, ссылка на файл/флаг, которого больше не существует, два списка одного
и того же факта, которые незаметно разъехались, или два правила, которые тихо
противоречат друг другу на каком-то реальном входе. `prompt-auditor` находит
всё это — как читал бы senior LLM-prompt-архитектор, а не просто text-diff.

1. Читает целевой файл (и его парный `SKILL.md`, если такой есть) целиком
2. Находит **дубли**: секция-рекап в конце промпта, дословно повторяющая
   правила из начала — решает, это осознанное усиление важнейших правил
   (primacy/recency) или бездумное повторение всего подряд
3. Находит **устаревшие ссылки** — но только после реальной проверки (`Grep`/
   `Read` по текущему репо), никогда по одному подозрению из формулировки
4. Находит **разъехавшиеся списки-двойники** — один и тот же факт (список
   обязательных секций, ключевых слов, порогов) в двух местах, которые больше
   не совпадают
5. Находит **скрытые противоречия** — два правила по отдельности корректны, но
   на каком-то реальном входе дают разные вердикты, без явного приоритета
6. Находит **сжимаемую прозу** — предложение без привязки к реальному
   инциденту, длиннее, чем того требует правило, которое оно несёт
7. Классифицирует каждую находку: `incident-tied` (переформулировать, никогда
   не удалять) vs `pure boilerplate` (безопасно сократить) — и предлагает
   точный before/after diff с обоснованием
8. Никогда не редактирует файлы сам — только предлагает; оркестратор
   применяет правки, живьём self-тестирует (на реальном историческом кейсе,
   если у агента есть дешёвый read-only вызов внешнего API — или структурным
   dry-run'ом, если нет) и решает revert vs ship

## Использование

```
/agent-audit my-agent                  # один таргет, по имени или пути
/agent-audit my-agent another-agent    # явный список
/agent-audit all                       # весь ростер .claude/agents/*.md
```

Никогда не запускается сам по себе — только по явному запросу, не часть
автономного хвоста оркестратора.

---

## Как это устроено (важно понять перед использованием)

`prompt-auditor` **не редактирует ничего** — у него нет `Write`/`Edit`
инструментов вообще, только `Read, Grep, Glob, Bash` (read-only). Он
находит и предлагает; применение правок, живой self-test и решение
revert/ship — задача **твоего оркестратора** (главной Claude Code сессии),
следуя алгоритму в `SKILL.md`. Суб-агенты не спавнят суб-агентов — поэтому
шаг живого self-теста физически не может жить внутри самого `prompt-auditor`.

## Структура файлов

```
.claude/
  agents/
    prompt-auditor.md         ← суб-агент (read-only, только находит + предлагает)
  skills/
    agent-audit/
      SKILL.md                ← скилл /agent-audit (координирует auditor + apply/self-test/confirm у оркестратора)
```

Никакого Python-пакета, никакого `pip install` — это чистый набор промптов.
Просто скопируй `.claude/agents/prompt-auditor.md` и `.claude/skills/agent-audit/`
в свой проект.

## Установка

### Требования

- [Claude Code](https://claude.ai/code) CLI
- Свой собственный ростер `.claude/agents/*.md` суб-агентов, который есть что аудировать

### Установка

```bash
git clone https://github.com/hereisnick7/agent-audit.git
```

Скопируй нужное в свой проект:
```bash
cp agent-audit/.claude/agents/prompt-auditor.md your-project/.claude/agents/
cp -r agent-audit/.claude/skills/agent-audit your-project/.claude/skills/
```

### Запуск

```bash
cd your-project
claude
```

```
/agent-audit all
```

Инструмент подтвердит перед тяжёлым многофайловым проходом ("Полный ростер —
N файлов. Погнали по всем, или начнём с нескольких?") и никогда не применит
правку без твоего явного подтверждения после self-теста.
